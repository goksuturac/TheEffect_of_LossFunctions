#  INHERENT CLASS IMBALANCE in LESION SEGMENTATION: THE EFFECT of LOSS FUNCTIONS

 COVID-19 lezyon segmentasyonu kapsamında, sınıf dengesizliği ve lezyon değişkenliği problemlerini ele almak amacıyla herkese açık olan COVID-19 BT veri setleri üzerinde eğitilen U-Net tabanlı model kullanılarak kayıp fonksiyonlarının performansı karşılaştırılmıştır. Gerçekleştirilen analizler, farklı kayıp fonksiyonlarının hem sınıf dengesizliği hem de lezyonların yapısal çeşitliliği karşısındaki performanslarını kapsamlı bir şekilde ortaya koymaktadır.
